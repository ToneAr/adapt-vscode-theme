# Changelog

All notable changes to the Adaptive VS Code extension pack will be documented in this file.

## [Unreleased]

### Added
- Cursor support: documented installing from Open VSX and added `publish:openvsx` scripts

## [0.0.1] - 2026-01-22

### Added
- Initial release of the Adaptive VS Code extension pack
- Bundles Adaptive Theme (color theme) and Adaptive Icons (icon theme)
- Cross-platform system accent color detection (KDE, GNOME, macOS, Windows)
- Real-time accent color change monitoring
- Custom accent color override option
- Support for external icon theme conversion
